# Mesto — лабораторная работа №4

Адаптивная фотогалерея с подключением к API. Вариант 1 — окно статистики карточки: автор, дата создания, количество лайков и список пользователей, оценивших фотографию.

- [Сайт](https://flareopti.github.io/mesto-public/)
- [Исходный код](https://github.com/flareopti/mesto-private)
- [Сборка](https://github.com/flareopti/mesto-public)

## Возможности

- Редактирование профиля и аватара.
- Добавление карточек и удаление своих карточек с подтверждением.
- Постановка и снятие лайков, просмотр фотографий.
- Статистика карточки с актуальными данными сервера.
- Валидация форм, состояния загрузки и обработка ошибок.
- Управление модальными окнами мышью и клавиатурой.

Стек: HTML, CSS, JavaScript, Vite, Fetch API. Основа — [шаблон Яндекс Практикума](https://github.com/Yandex-Practicum/mesto-ad).

## Запуск

Требуется Node.js 22.12 или новее.

```sh
npm ci
```

При первом запуске создайте `.env.local` по образцу `.env.example` и заполните настройки API:

```dotenv
VITE_MESTO_GROUP=apf-cohort-203
VITE_MESTO_TOKEN=ваш_учебный_токен
```

```sh
npm run dev
```

Приложение откроется в браузере по адресу `http://127.0.0.1:5173/`. Если порт занят, Vite укажет другой адрес.

## Команды

| Команда | Назначение |
| --- | --- |
| `npm run dev` | Сервер разработки |
| `npm test` | Проверки приложения, SSH-агента и публикации |
| `npm run build` | Сборка в `dist/` |
| `npm run preview` | Локальный просмотр сборки |
| `npm run deploy` | Сборка и публикация в публичный репозиторий |

## Публикация

Исходники хранятся в `mesto-private`, содержимое `dist/` публикуется в `mesto-public`. Для локального деплоя укажите в `.env.local`:

```dotenv
PUBLIC_PAGES_REPO=flareopti/mesto-public
PUBLIC_PAGES_BRANCH=main
```

Нужен SSH-доступ к GitHub. Для ключа с нестандартным именем задайте `MESTO_SSH_KEY=/полный/путь/к/ключу`. Скрипт запросит пароль ключа в интерактивном терминале, если ключ ещё не загружен в SSH-агент.

```sh
npm run deploy
```

В `mesto-public` настройте **Settings → Pages → Deploy from a branch → main → / (root)**.

Для автоматической публикации при push в `main` добавьте в Actions Secrets приватного репозитория:

- `VITE_MESTO_TOKEN` — учебный токен API;
- `PUBLIC_PAGES_REPO` — `flareopti/mesto-public`;
- `PUBLIC_PAGES_TOKEN` — GitHub-токен с правом записи в публичный репозиторий.

Workflow выполняет тесты, собирает проект и публикует `dist/`. Файл `.env.local` исключён из Git; переменные `VITE_*` входят в клиентскую сборку.
